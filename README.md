# Simple JavaFX Greeting App

A lightweight Java GUI application built with JavaFX. It takes a user's name as input and displays a personalized greeting when a button is clicked.

## How It Works

1. Enter your name into the text box.
2. Click the **"Say Hello"** button.
3. The app displays `Hello, <Name>!`.

## Code Structure

- **`Label`**: Displays prompt instructions and the final greeting.
- **`TextField`**: Captures user input.
- **`Button`**: Triggers the greeting action on click using a lambda expression.
- **`VBox`**: Arranges all components vertically.

## Running the Code

Make sure you have Java JDK and JavaFX installed, then run `Main.java` inside your IDE (e.g., IntelliJ IDEA, Eclipse, or VS Code).
